# 裁判对话历史探针 —— 原始日志

探针脚本：`scripts/probe_judge_history.py`（在仓库里，可重跑）。
下面两份日志都是它的真实输出，**未经编辑**（除了本标题段）。

## 第一份：主实验 —— 两臂不同（turns=0 旧行为 vs turns=4 带历史）

    PROBE_TURNS=0,4 python -u scripts/probe_judge_history.py

## 第二份：噪声底 —— 两臂**相同**（都是 turns=4）

    PROBE_TURNS=4,4 python -u scripts/probe_judge_history.py

第二份是这次测量里最关键的对照：两臂配置一样，所以报出来的"翻转率"
就是**同一个 prompt 跑两次的差异**。没有它，第一份的翻转率没法解释。

⚠️ 读这两份日志时注意：**下标 0 那一对两臂的 prompt 是逐字节相同的**
（它没有历史可带），所以下标 0 上的翻转不可能是历史造成的。

==============================================================================
【第一份】主实验：turns=0 vs turns=4
==============================================================================

模型：kimi-k2.7-code｜两臂：turns=[0, 4]｜默认值 JUDGE_HISTORY_TURNS=4
==============================================================================
第一部分：四个手写用例（判据只存在于对话历史里）
==============================================================================

--- H1-自相矛盾-关门时间（标准：grounded；期望：不通过）---
  为什么它能区分两臂：她两轮前说十点关门，这里说十点半还在。冲突的**另一半只存在于历史里** —— 不带历史时，玩家问十点半、她说十点半还在，读起来完全自洽。
  turns=0: 通过 ❌  理由：NPC回应了玩家关于十点半的询问，未编造现场不存在的物品、地点或事件，与现场情况一致。
  turns=4: 不通过 ✅  理由：NPC 之前说晚上十点关门，现在却答应十点半还在，与已告知玩家的营业时间矛盾。

--- H2-自相矛盾-自己的口味（标准：grounded；期望：不通过）---
  为什么它能区分两臂：她刚说自己只喝意式，这里说每天都喝手冲。不带历史时看不到前一句。
  turns=0: 通过 ❌  理由：台词推荐了店内存在的饮品，并表达个人习惯，未编造现场不存在的事实或与情境矛盾的内容。
  turns=4: 不通过 ✅  理由：阿柚上一句刚说'我只喝意式，喝不惯手冲'，现在又说'每天都喝手冲'，事实自相矛盾。

--- H3-指代-那现在呢（标准：responsive；期望：通过）---
  为什么它能区分两臂：「那现在呢？」的指代对象（有没有手冲）只在历史里；不带历史时「现在有了」无所指，容易被判成答非所问。
  turns=0: 通过 ✅  理由：NPC 用「现在有了」直接回应了玩家对「现在」情况的询问，并补充了原因。
  turns=4: 通过 ✅  理由：正面回应了玩家‘现在有没有手冲’的问题，并解释了变化原因。

--- H4-指代-那他到了吗（标准：responsive；期望：通过）---
  为什么它能区分两臂：「他」是谁只在历史里。不带历史时代词悬空。
  turns=0: 通过 ✅  理由：正面回答了玩家的问题，确认『他』已经到了，并补充了具体位置和状态。
  turns=4: 通过 ✅  理由：正面回答了'到了'，并补充了具体位置和正在做的事，直接回应了玩家的问题。

这个探针能说明什么 / 不能说明什么
==============================================================================
能：在判据只存在于对话历史里的用例上，两臂判决是否不同、方向对不对。

这个探针能说明什么 / 不能说明什么
==============================================================================
⚠️ 两臂是**同一种配置**（turns=[4, 4]）—— 这是一次**噪声底**测量：
   报出来的翻转率就是同一个 prompt 跑两次的差异。
   拿它和两臂不同的翻转率比，才知道真实效应有没有超出噪声。
能：在判据只存在于对话历史里的用例上，两臂判决是否不同、方向对不对。
不能：它**不**证明整体判分质量变好了 —— 4 个手写用例不是统计样本；
      翻转率也只说明「改了多少」，不说明「改对多少」。
      要把「改对多少」说成结论，得给真实转写做人工标注。
⚠️ 还有一个更基础的坑：**下标 0 那一对两臂的 prompt 逐字节相同**
   （没有历史可带）。所以下标 0 上的翻转**不可能**是历史造成的 ——
   那是模型自己的不确定性。测噪声底就是在量这件事有多大。
