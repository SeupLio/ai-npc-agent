多 NPC 对话基准

量的是「NPC 之间能不能聊起来、聊得像不像话」——六维评测结构上看不见的那一块。
共 18 条用例、6 个维度，通过 18/18（100%）。全部离线运行，0 次模型调用，clone 下来就能复现。
这份读数不能说明什么。它衡量的是一条**确定的对话链路**是否接通：话有没有说给对的人、接不接得住、会不会复读、印象传不传得到。 它不衡量对话是否有趣、是否像真人 —— 那要真人玩家来判，不是工程能替代的（见 README 的「边界」一节）。 离线路径的词汇量是有限的，长对话的复读率有下界；接上模型之后同一个位置的表现会不同，那需要另外跑批。
